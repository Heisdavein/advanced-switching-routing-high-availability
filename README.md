# Advanced Switching, Routing & High Availability
Documentation Attached as PDF

A Cisco Packet Tracer networking lab series focused on advanced switching, dynamic routing, redundancy, and high availability.

## Overview

This project contains six Cisco Packet Tracer labs designed to build practical skills in enterprise networking.

The labs explore how different networking technologies work together to create networks that are reliable, scalable, and able to adapt to failures.

## Labs Covered

### 1. Router-on-a-Stick
Configured inter-VLAN routing using router sub-interfaces and 802.1Q encapsulation, allowing devices in different VLANs to communicate.

### 2. Rapid Spanning Tree Protocol
Configured Rapid PVST+, root bridge priorities, PortFast, and BPDU Guard to prevent switching loops, improve convergence, and protect access ports.

### 3. EtherChannel
Configured LACP to combine multiple physical links into a single logical Port-Channel, improving bandwidth and link resilience.

### 4. EIGRP
Configured EIGRP dynamic routing to allow routers to automatically exchange routing information and adapt when network paths change.

### 5. OSPF
Configured OSPF as an open-standard dynamic routing protocol for exchanging routing information and selecting optimal paths.

### 6. HSRP
Configured HSRP to provide a highly available default gateway using an Active Router, Standby Router, and shared Virtual IP address.
